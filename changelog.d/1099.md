### Added

- **The first MSFlexGrid model slice** (#1099): measured dimensions, cursor event order, selection text,
  TextMatrix/TextArray storage and Clip handling.

- **MSFlexGrid runtime binding** (#1099): a form holding a grid now runs, and code can set and read its
  dimensions, current cell, Text, TextMatrix and FormatString headings. Later grid members remain
  explicitly refused; drawing, input and saved-file fidelity follow separately.

- **MSFlexGrid programs can use selections and cell sizes** (#1099). RowSel, ColSel, FillStyle,
  Clip and TextArray are reachable from code, alongside ColWidth, RowHeight, ColAlignment,
  FixedAlignment reads and RowHeightMin assignments. Widths and heights round to pixels and
  invalid values retain the control's measured error numbers. Drawing and input follow separately.

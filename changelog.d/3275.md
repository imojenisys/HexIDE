### Fixed

- **A ListBox's `TopIndex` assignment raises `Scroll` when its top row changes** (#3275).
  The handler reads the new row, the last item clamps to the last page, and an index outside
  the list raises error 380. Assignments use standard Integer store coercion, accepting Long
  and numeric Variant values and raising error 6 on Integer overflow. Native-message event delivery remains pending.

- **A running ListBox reports vertical scroll-bar and keyboard scrolling** (#3275). Each changed
  top row raises `Scroll`, after `Click` for keys, with the new `TopIndex` already visible. Wheel
  input and `ListIndex` assignments continue to raise no `Scroll`. Scroll-bar arrows move one row
  using its laid-out height, including with Windows fonts and larger text.

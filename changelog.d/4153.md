### Added

- **Design-time font effects** (#4153): the managed Font dialog offers Strikeout and Underline with access keys, previews both effects and writes them to a form or control's saved Font block. Existing effects remain selected when the dialog reopens. The font name and style can be typed to select matching entries; choosing an entry fills its box. Font, style and size captions provide localized access keys and name their lists for accessibility. Strikeout and Underline automation names omit the access-key markers. The dialog opens with the font name selected and OK is the default. Typed sizes and Script remain pending.
